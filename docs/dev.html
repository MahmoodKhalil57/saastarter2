There is no build step, so the file you are reading IS the deployed source. Save a GitHub token here and every page grows a </> button: freeze the page, edit the DOM — by hand, DevTools, or a Claude browser extension — review the line diff, and commit. The push is the deploy.

  1. Create a fine-grained personal access token : Only select repositories → this repo, Repository permissions → Contents: Read and write , shortest expiration you can live with.
  2. Paste it below. It is stored in this browser's localStorage only — never sent anywhere but api.github.com . Anyone with this browser profile (or an XSS on this origin) can use it, which is exactly why the token must see one repo and nothing else.
